サポート

USB でつないだ MTP の機器 (GoPro など) を、Finder のサイドバーに出す Mac のアプリです。

お問い合わせ

GitHub の Issues に書いてください。

使い方

  1. MTPort を開き、「常駐して使う」を押します。
  2. 求められたら、「システム設定」→「一般」→「ログイン項目と機能拡張」で MTPort をオンにします。
  3. 機器を USB でつなぐと、Finder のサイドバーの「場所」に出ます。

ファイルを消せない・足せない

写真・プレビュー・Google Drive などが動いていると、macOS の写真の取り込み (ptpcamerad) が機器を使います。そのあいだ、MTPort は読む・Mac に写すことだけができます。これらのアプリを終了すると、1 分ほどで消せるようになります。

GoPro にファイルを足せない

GoPro は、USB の接続でファイルの追加を受け付けません (カメラの仕様)。読む・Mac に写す・消すはできます。

機器が出てこない

  • 機器の USB の設定を「MTP」や「ファイル転送」にしてください。
  • MTPort の画面で、常駐の部品が動いているか確かめてください。

Support

A Mac app that shows MTP devices connected over USB (such as GoPro cameras) in the Finder sidebar.

Contact

Please open an issue on GitHub.

How to use

  1. Open MTPort and click "Run in the Background".
  2. If asked, turn on MTPort in System Settings → General → Login Items & Extensions.
  3. Connect your device over USB. It appears under Locations in the Finder sidebar.

I cannot delete or add files

While Photos, Preview, Google Drive or similar apps are running, macOS photo import (ptpcamerad) uses the device, and MTPort can only read files and copy them to your Mac. Quit those apps; deleting works again about a minute later.

I cannot add files to my GoPro

GoPro cameras do not accept new files over USB. You can open, copy and delete files.

My device does not appear

  • Set the device's USB mode to MTP or File Transfer.
  • Check in the MTPort window that the background agent is running.
